# Время проверки

Длительность в параметрах задаёт передачу данных. Время подготовки, соединения, получения итогового отчёта и проверки пинга считается отдельно. На экране видно текущий этап, его время и общее время прогона; события сохраняются в поле `Stages` локального JSON.

Для времени используется монотонный таймер: изменение часов Windows не меняет отсчёт.

| Этап | Как ограничен |
|---|---|
| Пинг до и после | По 2 секунды; отдельный запрос укладывается в оставшееся время |
| Проверка версии | До 5 секунд; повторяется только для нового хэша exe |
| Начало передачи iPerf | До 4 секунд на порт; пустое соединение не забирает время самого теста |
| Передача | Длительность из параметров; начало определяется по событиям измерителя |
| Итог UDP iPerf2 | До 5 секунд после завершения отправки |
| Итог iPerf3 | До 10 секунд после передачи |
| Завершение остановленного процесса | До 3 секунд на подтверждение выхода; новая попытка не начинается до выхода |
| Общий срок | Учитывает подготовку, число портов, передачу, отчёт и пинг; максимум 120 секунд на один запуск |

Если приходится подобрать другую версию iPerf2, первый профиль получает бюджет на два запуска. Остальные профили используют подтверждённый клиент. Команда `--version` не запускается заново перед каждым профилем; SHA-256 исполняемого файла продолжает проверяться.

Пинг под нагрузкой запускается вместе с передачей iPerf и останавливается при переходе к итоговому отчёту. Подготовка и ожидание ответа не попадают в эту выборку. Для HTTP этап включает соединение и передачу; скорость рассчитывается по фактически прошедшему времени. Предел полезных HTTP-данных увеличен до 7,5 ГБ, чтобы быстрые подключения не заканчивали тест после прежних 512 МиБ.

Полный UDP-итог отправителя без отчёта сервера сохраняется как локальный TX. Истечение срока ожидания отчёта не превращает завершённую отправку в «не удалось передать». Остановка пользователем остаётся отдельным результатом.

Цвета показателей спокойные и одинаковые во всём интерфейсе: мятный — хорошее значение, песочный — отклонение, коралловый — проблема, серый — неизвестно. Подписи и подсказки объясняют смысл цвета.
