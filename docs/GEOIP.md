# IP и автоматический выбор сервера

Логика перенесена из предоставленных пользователем Python-файлов GeoIP и определения внешнего IPv4. При запуске программы запросы выполняются в фоне. При каждом нажатии «Проверить скорость» внешний IP определяется заново **до нагрузки**. Ожидание ограничено 3,5 секунды; недоступность IP-сервисов не запрещает тест скорости. Полученный позже ответ не меняет ручной выбор, собственный сервер или активную передачу.

Для внешнего IPv4 используются STUN Binding-запросы к Cloudflare и Twilio. Проверяются transaction ID, magic cookie, длины и публичность XOR-MAPPED-ADDRESS. Два одинаковых ответа образуют кворум. Резервный адрес определяется по HTTPS через ifconfig.me/ipify. Если внешний STUN-адрес отличается от видимого через HTTPS, шапка отображает оба, а GeoIP использует выбранный базовый адрес.

При включённом переключателе GeoIP приложение отправляет этот IP в `https://ipwho.is/<IP>` для приблизительных координат и в RIPEstat network-info для ASN. Ошибка, ответ о другом IP, некорректные координаты или недоступность сервиса сохраняют неизвестность. JSON ограничен 64 КиБ, запрос — четырьмя секундами. Географический результат кэшируется в памяти на 15 минут для данного IP; внешний IP проверяется заново при обновлении. Переключатель хранится в `%LOCALAPPDATA%/SpeedForge/preferences.json`.

Ближайшая точка выбирается по сферическому расстоянию до города сервера. Координаты 48 городских записей получены из GeoNames `cities15000.zip`; неизвестные города/региональные записи не ранжируются. При равном расстоянии предпочтение получают точки с наблюдавшимися двумя направлениями, затем HTTPS с приёмной точкой. Исторические ошибки не запрещают повторный ручной тест. Определение по IP и координаты центров городов не гарантируют точного положения устройства или минимальной сетевой задержки.

HTTPS-подключения для определения адреса создаются заново, а запросы запрещают кэширование. Поэтому после включения или выключения VPN не используется старое соединение к IP-сервису. Готовый STUN-кворум сохраняется даже при зависшем HTTPS. GeoIP/ASN уточняются отдельно в фоне, без повторного определения IP и без смены выбранного для проверки сервера.

Верхняя строка позволяет копировать IP без дополнительных кнопок. При отключённой геолокации IP виден и обновляется по кнопке, но GeoIP/ASN не запрашиваются и сервер автоматически не меняется.

Колонка **«Исходный IP»** в истории содержит внешний адрес, определённый перед началом этого прогона. Он фиксируется один раз для обоих направлений и сохраняется в JSON вместе с источником и временем определения. Позднее обновление шапки не изменяет сохранённую запись. Если HTTPS и STUN дали разные адреса, второй адрес виден в подсказке колонки: при разделённых маршрутах VPN наблюдаемый IP может зависеть от протокола. Это адрес из проверки IP, а не подтверждение адреса, который видел каждый тестируемый сервер.

Для старых записей и запусков, перед которыми IP определить не удалось, показано «—». Текущий адрес не подставляется в прежние результаты. IP сохраняется только в локальной истории и выбранных пользователем экспортах.
