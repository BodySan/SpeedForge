# SpeedForge 1.1.1

После подключения или отключения VPN больше не нужно перезапускать программу ради обновления IP. Нажмите **«Проверить скорость»** — перед нагрузкой приложение заново определит внешний адрес и обновит строку сверху. Старые HTTPS-подключения к IP-сервисам не используются.

В истории появилась колонка **«Исходный IP»**. Она показывает адрес перед началом соответствующего прогона. Он сохраняется вместе с результатом и остаётся прежним при последующих изменениях подключения. Для старых записей без IP и проверок с недоступными IP-сервисами показано **«—»**.

Определение IP занимает не более 3,5 секунды. Если службы недоступны, проверка скорости всё равно запускается. Геолокация уточняется отдельно в фоне; выбранный сервер при нажатии кнопки не меняется. Этой же кнопкой можно отменить подготовку до начала нагрузки.

При разных адресах через STUN и HTTPS второй IP показан в подсказке истории. Это помогает заметить разные маршруты VPN для UDP и HTTPS. В колонке сохраняется наблюдаемый внешний адрес, а не утверждение о том, какой IP видел каждый сервер.

Настройки серверов, тарифы Билайна, оформление и пояснение об особенностях тестируемых серверов сохранены. Приложение по-прежнему запускается из одного exe без установки.
