# SpeedForge 1.0

Версия приложения и Windows exe — 1.0.0. Новая иконка содержит десять размеров от 16 до 256 пикселей. Системная рамка, заголовок и кнопки окна оформлены в тёмной теме Windows; стандартные операции окна сохраняются.

Главный экран: одна кнопка запуска/остановки, отдельные приёмная и исходящая скорости, график и задержка. Дополнительные параметры сворачиваются. Исправлено применение протокола и доступных направлений собственного сервера, стабильный ID собственной точки и сравнение разных измерительных методов.

Билайн: все восемь профилей UDP из предоставленного архива автоматически проходят одной кнопкой. Нагрузка 100/1000 Мбит/с относится к каждому из 1/5/10/20 потоков. Итог использует лучший полный Server Report; локальная статистика TX без ACK остаётся в debug и не попадает в карточку/историю скорости. Обратное направление проверяется отдельным запуском. [Подробная методика](BEELINE_PROFILES.md).

Встроены .NET, iPerf2 2.2.2, iPerf3 3.22, необходимые библиотеки, лицензии и архивы исходников компонентов. Для запуска достаточно одного `SpeedForge.exe`.

Песочница проверяет настоящие измерители, ошибки, отмену, направления, многопоточные профили, оформление и ситуацию с каналом 100 Мбит/с при нагрузке 1 Гбит/с. Команды повторения: `./build-windows.ps1`, затем `./tests/run-sandbox.ps1`. Контрольные результаты и снимки интерфейса сохраняются в `sandbox-output`. Статическая проверка: `python static_audit.py`; она дополняет сборку и исполнение тестов.

Публичный репозиторий: [BodySan/SpeedForge](https://github.com/BodySan/SpeedForge). Portable exe: [выпуски](https://github.com/BodySan/SpeedForge/releases).

Проверки 12.10.2026: 84 регрессионных, 25 сценариев песочницы, 26 сценариев интерфейса — 135/135, ошибок 0. Контрольная сборка без предупреждений. Сводные результаты: [QA_1.0.json](QA_1.0.json).
