# SpeedForge 1.1.0

Теперь адрес любого встроенного сервера можно исправить во вкладке **«Серверы»**: выберите строку, введите новый адрес и нажмите **«Сохранить адрес»**. Изменение сохраняется между запусками. Порты, метод проверки и пути HTTP-файлов остаются прежними. Кнопка **«Вернуть исходный»** отменяет исправление.

Для Билайн iPerf2 скорость тарифа выбирается из списка: **100, 200, 300…1000 Мбит/с**. Выбранное значение запоминается. Это общая нагрузка одной исходящей UDP-проверки; программа сама распределяет её между потоками. Проверка входящего трафика на этой точке не запускается.

После завершения отправки программа не тратит время на дополнительные ожидания UDP-отчёта. Если полный отчёт сервера получен, показана подтверждённая скорость приёма. Если его нет, результат подписан как **UDP-отправка с ПК**: он не подтверждает доставку пакетов и отсутствие потерь. Скорость тарифа не подставляется в результат.

С момента публичной версии 1.0.1 также доработаны тайминги, разбор ответов измерителей и история. Пинг и джиттер расположены рядом, значения скорости, IP, времени и качества выделены спокойными цветами. Приложение запускается из одного exe без установки; iPerf2 и iPerf3 встроены.

Исправленные адреса находятся в `%LOCALAPPDATA%\SpeedForge\server-overrides.json`. Их можно перенести на другой компьютер вместе с этим файлом. Для нового адреса прежние контрольные наблюдения не считаются актуальными; после изменения выполните проверку.

Внизу главного экрана добавлено пояснение: **«Из-за особенностей тестируемых серверов результаты могут отличаться от фактической скорости линии»**.

Сборка проверена в локальной песочнице с настоящими iPerf/HTTP-процессами и проверками интерфейса. Результаты и границы проверки указаны в `QA_1.1.0.json`.
