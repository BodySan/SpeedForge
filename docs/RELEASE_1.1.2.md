# SpeedForge 1.1.2

Исправлены ошибки графика, повторного подключения и обработки результатов, найденные при проверке версии 1.1.1.

В ручном двунаправленном iPerf3-тесте на графике теперь видны оба результата приёмников. Ошибка такого теста очищает обе карточки. Локальные интервалы отправки iPerf не подменяют подтверждённую скорость отдачи: точка появляется после отчёта сервера.

Собственный HTTP Endpoint показывает прогресс по подтверждённым блокам. Прежний предел 256 МиБ убран; общий предел полезного HTTP-трафика составляет 7,5 ГБ на направление. Внешний таймаут оставляет время для завершения блока по правилам Endpoint. Кнопка проверки направлений работает и для собственного адреса.

Если iPerf3-сервер занят или оборвал управляющее соединение, программа делает одну повторную попытку через 1,2 секунды. При смене порта очищаются данные неудачной попытки. Исправлены сохранение версии измерителя в streaming JSON и направление загрузки в CSV iPerf2.

В каталог добавлены HTTPS-файлы зеркал Билайна и Truenetwork. У Selectel используется файл 1 ГБ, чтобы реже переподключаться. Эти точки проверяют загрузку; отдача им не приписывается. Для тестовых файлов допускается также тип binary/octet-stream, а страницы, JSON и сжатые ответы по-прежнему отклоняются.

Режим Билайн iPerf2 остаётся исходящим UDP-тестом с выбором тарифа 100–1000 Мбит/с. Реальные проверки тарифов 100, 500 и 1000 Мбит/с завершились примерно за 10,3–10,6 секунды. Без отчёта сервера показана локальная отправка, а не подтверждённая скорость линии.

Обновление IP перед запуском, исходный IP в истории и сохранённые правки адресов проверяются вместе с остальными сценариями. Приложение по-прежнему запускается из одного exe без установки .NET.

В переносимую сборку включён патч безопасности .NET 10.0.13 от 13 октября 2026 года. Официальный SDK 10.0.402 проверен по SHA-512 перед сборкой. iPerf2 2.2.2 и iPerf3 3.22 соответствуют последним стабильным выпускам на дату проверки; старый iPerf2 2.0.8 сохранён для совместимости с Билайном.
