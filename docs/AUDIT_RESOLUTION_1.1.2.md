# Проверка аудитов 1.1.1

Подтверждённые ошибки исправлены в 1.1.2: график и сброс карточек bidir, прогресс и таймаут собственного Endpoint, прежний предел 256 МиБ, повтор после занятости/обрыва control-соединения, очистка предыдущей попытки, сохранение start/version в streaming JSON, направление CSV и прогресс HTTP только по принятым блокам. Цвета легенды соответствуют направлениям.

Консольное сравнение Билайна выполнено старым клиентом 2.0.8: 5×200 Мбит/с дали 954 Мбит/с отправки, 10×100 — 939 Мбит/с. Полного отчёта сервера в обоих случаях не было. Поэтому раскладка 5 потоков для старших тарифов сохранена: суммарная нагрузка правильная, преимущества 10 потоков на этом подключении не обнаружено. Тариф не определяет реальную скорость доставки.

Завершение отправки Билайна без ожидания приёмника сохранено по выбранной методике. Объём без ACK и незавершённые HTTP-блоки не выдаются за подтверждённую отдачу. TCP end.sum без подтверждения стороны приёмника также не принимается автоматически.

HTTP-кандидаты проверены по точным опубликованным ссылкам, 8 секунд, 4 потока, без ограничения скорости. HTTPS-зеркала Билайна и Truenetwork добавлены после успешной загрузки. Файлы Selectel 100 МБ, 1 ГБ и 10 ГБ дали близкую скорость, около 480–500 Мбит/с; замедление крупных файлов из аудита на этом маршруте не подтвердилось. Используется 1 ГБ, чтобы реже повторять запросы.

Заключительный прогон проверил девять записей по TCP/HTTP и две по UDP. МТС Краснодар и Билайн Воронеж подтвердили оба TCP-направления; HOSTKEY — оба HTTP-направления. Московский МТС по TCP был занят, после ограниченной повторной попытки скорость не показана; по UDP оба направления измерены. Это наблюдения конкретного подключения, а не постоянные свойства серверов или доказательство исчерпанности российского пула.

Проверены 125 регрессий, 37 сценариев песочницы и 43 сценария интерфейса, без ошибок. Смена IP, поздний ответ, отмена, сбой IP-служб, история и сохранение адресов проверены управляемыми сценариями. Системный VPN пользователя не переключался. Числа публичных измерений и SHA-256 exe находятся в [QA_1.1.2.json](QA_1.1.2.json).

При проверке обновлений использованы [официальные данные Microsoft](https://builds.dotnet.microsoft.com/dotnet/release-metadata/10.0/releases.json), [новости ESnet iPerf3](https://software.es.net/iperf/news.html) и [файлы проекта iPerf2](https://sourceforge.net/projects/iperf2/files/). SDK 10.0.402 проверен по опубликованному SHA-512; переносимый exe включает .NET 10.0.13. Устанавливать SDK или .NET пользователю не требуется.
