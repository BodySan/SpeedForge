# SpeedForge 1.0.3 — локальная сборка

Для Билайн iPerf2 оператор и город заменены полем «Скорость предусмотренная тарифом». Программа выполняет один исходящий UDP-тест. Тариф задаёт суммарную нагрузку; параметры потоков находятся в debug.

Автоматический reverse удалён. После полного итога отправки прекращаются дополнительные ожидания UDP-отчёта. По умолчанию нагрузка длится 10 секунд; время пинга показано отдельно.

Если полный отчёт сервера уже пришёл, используется подтверждённая скорость приёма. Если отчёта нет, показана **UDP-отправка с ПК** с пояснением. Она не доказывает пропускную способность линии: пакеты могли быть потеряны дальше по маршруту. Тариф не подставляется в измеренный результат.

Цветом выделены значения скорости, внешний IP, число серверов, пик графика, оси, время проверки, выбранный сервер и тариф. Джиттер и потери сохраняют цвета качества; неизвестные значения остаются нейтральными.

Значок внутри exe проверен штатным Windows API в размерах 16 и 32 пикселя. Владелец подтвердил, что значок панели задач появился после перезапуска.

Сборка и исходники подготовлены локально. На GitHub ничего не опубликовано.
