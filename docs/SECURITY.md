# Обработка недоверенных данных

Измерительные серверы и пользовательский ввод считаются недоверенными. Код передаёт аргументы процессов через `ProcessStartInfo.ArgumentList`, проверяет адреса и порты, закрепляет разрешённый IP для HTTP-подключения, запрещает автоматические HTTP-редиректы и сохраняет стандартную проверку TLS-сертификатов. Частные адреса доступны только при включённой настройке локальной сети.

Встроенные iPerf2/iPerf3 и DLL проверяются по SHA-256 перед запуском. Произвольные exe автоматически не скачиваются. Пользовательский измеритель выбирается отдельно во вкладке «Инструменты». Тест ограничен длительностью, общим сроком выполнения и единственным активным запуском; отмена останавливает принадлежащий тесту процесс.

HTTP-движок отклоняет HTML, JSON, сжатые и пустые ответы вместо тестовых данных. Отчёт iPerf2 TX без Server Report не считается скоростью канала; статистика приёма и отправки хранится отдельно. Неполные отчёты отдельных потоков сохраняются с частичным статусом.

Песочница воспроизводит некорректные ответы, TLS-ошибки, зависания, отмену, отсутствие ACK и потерю UDP-датаграмм. Эти проверки не являются независимым аудитом безопасности нативных измерителей или Windows. Подробные логи и технический JSON могут содержать сетевые адреса и версии компонентов; они сохраняются локально и не отправляются автоматически.

Для воспроизведения ошибки используйте вкладку «Отладка». Перед публикацией журнала проверьте содержащиеся в нём данные. Исходники сторонних компонентов и их лицензии доступны во вкладке «Инструменты».
