# SpeedForge 1.0.2 — локальная сборка для проверки

Восстановлены четыре профиля Билайна на 500 Мбит/с из исходного Python-кода. Автоматический прогон теперь включает 12 комбинаций: 100, 500 и 1000 Мбит/с с 1, 5, 10 и 20 потоками.

Пинг и джиттер показаны рядом. Для UDP джиттер и потери берутся из отчёта принимающей стороны; для HTTP и TCP показано изменение соседних ICMP-ответов до нагрузки. Источник подписан. Зелёный, жёлтый и красный помогают читать показатели; пороги доступны в подсказках. Прочерк означает отсутствие данных.

Если UDP-отправка завершилась, но отчёта сервера нет, отдельно показан локальный TX. Он не подменяет скорость приёма. Таймаут после завершённой отправки сохраняет эту статистику вместо общего сообщения о неудавшемся тесте.

Каталог проверяется последовательно на максимальной скорости, без прежнего ограничения аудита до 10 Мбит/с. Живые результаты и проверки интерфейса приложены к локальной сборке. Они описывают проверенное подключение, а не гарантируют доступность сервера из каждой сети.

Сборка пока не опубликована на GitHub: публикация ожидает подтверждения владельца.

Тайминги разделены на этапы: соединение, передача и итоговый отчёт имеют отдельные сроки. Пинг под нагрузкой начинается с самой передачи. Весь прогон показывает общее время; версия проверенного exe кэшируется по хэшу. [Подробнее о времени проверки](TIMINGS.md).

Палитра стала спокойнее: мятный, песочный и приглушённый коралловый для качества; лавандовый и голубой помогают различать отдачу и задержку. Локальный TX появляется по реальным интервалам во время отправки и не рисует график приёма.

Учтены ошибки старого Python-тестера: ручной двусторонний тест требует ненулевых принятых байтов обоих направлений. Реально низкая скорость сохраняется. После отмены или таймаута программа подтверждает завершение дочернего процесса перед новой попыткой.
